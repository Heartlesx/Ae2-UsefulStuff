# AE2 Useful Stuff（AE2US）

面向 Minecraft 1.12.2 的 **AE2 Unofficial Extended Life（AE2UEL）** 附属模组：围绕 ME 网络的接口投料、样板上传与分类路由、配方查看与库存显示，减少大型自动化里的重复操作。

## 功能一览

- **智能阻挡（投料控制）**：ME 接口持续补料同一样板，其它样板暂缓到目标完成。
- **样板终端增强**：一键上传到已命名接口；按 HEI 分类 / 模具自动填写上传目标；接口行内改名（组 / 单台 / 映射同步）；定位接口时红框透视高亮（15 秒、可同时多个）。
- **配方导入增强**：从 HEI 导入配方即记录分类与模具，样板自动分流到对应接口；处理配方支持通用电路替换。
- **矿典总线**：矿典输出总线与矿典存储总线，规则支持用 AE2 内存卡复制。
- **大容量设备**：2048M 存储元件（物品 / 流体各一件，256 类型）；六档高级并行处理单元（一块顶 N 块原版）；六档高级合成存储器（256k～16384k）。
- **镜像样板供应器**：贴片部件绑定多个现成 ME 接口，共享它们的样板，288 个只读样板槽，跟随源接口的阻挡与优先级；配套镜像绑定器。
- **中键拾取**：带着无线终端对着世界方块按中键，直接从网络取一整堆到快捷栏；网络没有但有样板时直接弹出原生下单界面。
- **其它**：合成产出置顶、Shift 查看样板产物预览的兼容修复。

## 环境要求

- Minecraft 1.12.2（Forge 14.23.5.2860）
- AE2 Unofficial Extended Life v0.56.7 + MixinBooter
- 针对 GregTech Lite 整合包（GregTech / GT Lite Core / Fluid Craft for AE2 / HadEnoughItems）做了适配，相关功能以这些模组实际安装且配方可识别为前提

## 下载与安装

- 发行包见本仓库的 **Releases** 页面。
- 安装时请先删除旧版文件，再放入新包；不要同时放两个 `ae2us` 的 JAR。

## 从源码构建（可选）

开发环境锁定 JDK 8（ForgeGradle 3 + Gradle 4.9）：`gradle.properties` 里的 `org.gradle.java.home` 请改为本机 JDK 8 路径。`libs/` 内的第三方依赖 jar 不随仓库提供，需自行准备。
