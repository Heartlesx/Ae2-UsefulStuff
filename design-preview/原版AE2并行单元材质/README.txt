原版 AE2「并行处理单元」（合成加速器）贴图 —— 按状态分类
来源：整合包内 ae2-uel-v0.56.7.jar；全部为 16×16 PNG。
（AE2 为 LGPL：本文件夹仅供外观改造参考，不要直接把原图打包进本模组，成品需为重新自绘的版本。）

一、原版这些图怎么用（大白话）
- 单独摆放（未成型）：整个方块面就是 accelerator.png 一张图。
- 拼进 CPU 结构（成型）后，每个面变成两层：
  1) 边框：只画在整个结构的外沿和外角上。两块相邻的 CPU 方块之间不画边框，
     核心贴图直接连过去 —— "连成一体"的观感就来自这里。
  2) 核心：light_base.png 打底，上面叠 accelerator_light.png。
- 通电（CPU 正在合成）：亮层满亮发光；未通电（成型但空闲）：同一张亮层按普通光照渲染，看起来变暗。
  原版"通电/未通电"不是两张图，只是同一张亮层的亮度差别。

二、文件夹对照（括号内为原版术语，方便写生成提示词）
1_未连接（未成型 / unformed）
    accelerator.png —— 白框 + 品红方芯；物品栏图标同款。
2_已连接（成型 / formed frame）
    ring_corner.png（结构转角的 3×3 小块）
    ring_side_hor.png（横条）
    ring_side_ver.png（竖条）
3_通电（合成中 / powered）
    light_base.png（核心底盘，白十字纹）+ accelerator_light.png（紫十字亮层，满亮）
4_未通电（成型空闲 / unpowered）
    与 3 完全相同的两张图（原版同图，仅亮层亮度不同；分开放两份，方便你对两个状态分别提改造要求）

三、改造时可以这么想
- 想表达"连接/未连接"：参照 2 的边框思路 —— 有邻块相连的方向不画边框，形成连续的整片结构。
- 想表达"通电/未通电"：本模组方块本身就是三态贴图（未成型 / 成型未通电 / 成型通电），
  可以让生成模型给两个状态各出一张，不必被原版"共用一张亮层"限制。

备注：accelerator.png 与 ring_corner.png 无透明通道（RGB），其余四张带透明背景（RGBA）。
